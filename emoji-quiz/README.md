# 絵文字当てクイズ

「絵文字当てクイズ」と投稿すると、ワークスペースのカスタム絵文字からランダムに出題します。

出題画像は縦横比を保って最大512pxに拡大し、Cloudinary経由で画像として表示します。GIFはアニメーションを維持します。画像URLや代替テキストには答えを含めません。

出題メッセージのスレッドに、コロンを付けず登録名だけを回答してください。前後の空白を除いて完全一致で判定します。同じ画像URLを指す別名も正解です。不正解でも再回答できます。正解するか60秒経過すると終了し、答えを表示します。途中のヒントはありません。同時に進行できるクイズは1問です。

既存のCloudinary設定と、`emoji.list` を利用できるSlackトークン（`emoji:read`）が必要です。

```sh
npm run dev -- --only emoji-quiz
npx vitest run emoji-quiz/index.test.ts
```
